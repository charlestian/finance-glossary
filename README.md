## 功能

- **全局搜索**：在所有分组中搜索术语
- **白天 / 夜晚主题**：一键切换，夜晚模式下整个界面都变成深色
- **节点详情**：点击分组节点，查看该组的术语表；表中的链接可以跳转到对应节点
- **移动端适配**：在手机上，节点详情面板会铺满屏幕宽度

## 术语格式

每个分组页有一张术语表：

| 中文名 | 英文名 | 释义 |
|---|---|---|

- 释义都经过在线核对，用简洁的中文写成
- 重复的术语会合并成一条
- 表格按中文名的拼音排序

## 构建方式

内容维护在一个 Markdown 知识库里，每个分组一页，「术语库」页作为总导航。图谱页由这些 Markdown 生成，产物是一个自包含的单文件 HTML，部署时作为 `index.html` 发布。
